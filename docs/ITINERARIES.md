# Itineraries used by the simulation

Generated by `python3 src/build_routes.py`. Do not edit by hand.

## Where the timetable comes from

- Publisher: SNCF (official open data)
- Dataset: SNCF timetable (TGV, Intercités, TER) in GTFS format, [https://transport.data.gouv.fr/datasets/horaires-sncf](https://transport.data.gouv.fr/datasets/horaires-sncf)
- File: `https://eu.ftp.opendatasoft.com/sncf/plandata/Export_OpenData_SNCF_GTFS_NewTripId.zip`
- Feed version: 2026-11-26, valid from 2026-11-26 to 2027-04-30
- Published on: 2026-11-26
- Reference days used: 2026-12-08 (weekday), 2026-12-12 (weekend)

## What we added by hand

- Track layout of each line (single or double track), with the source listed under each itinerary.
- "Big city" stations (city above 100,000 inhabitants): Grenoble, Lille, Lyon, Paris. An incident within 10 km of one counts as *urban*; within 25 km as *near a maintenance base* (assumption).
